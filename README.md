# Jensy Sherine J — Portfolio

A personal portfolio website built with React + Vite.

## Run it locally

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Project structure

```
src/
  components/
    Navbar.jsx
    Hero.jsx
    About.jsx
    Education.jsx
    Skills.jsx
    Project.jsx
    Achievement.jsx
    Certification.jsx
    ForestWaveArt.jsx   (SVG illustration for the project card)
    Waveform.jsx        (animated waveform, the site's signature motif)
    Footer.jsx
  App.jsx
  main.jsx
  index.css
```

All content reflects only the information provided by the student — no
fabricated internships, projects, links, or skills.
